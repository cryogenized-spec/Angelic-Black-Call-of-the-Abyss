# Angelic Black PWA icons

Upload the authored PWA artwork into this folder.

Required files referenced by `manifest.json`:

- `icon-192.png` — 192×192 PNG, square app icon.
- `icon-512.png` — 512×512 PNG, square app icon.

Recommended artwork: the Necro Queen's crown/silhouette or the Angelic Black insignia on a dark gothic background with generous safe margins. Avoid tiny text because the icon will be displayed at very small sizes.

Do not place the icon in `.public`; this project uses `assets/icons/` so the static GitHub Pages path is explicit and version-controlled.
